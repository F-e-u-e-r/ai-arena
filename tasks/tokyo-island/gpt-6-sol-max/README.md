# Floating Tokyo / 浮遊東京

以原生 HTML、CSS 和 Three.js 製作的單頁 3D 浮空島。東京鐵塔位於中央，周圍有富士山、鳥居、五重塔、楓樹、石徑與池塘。場景中的模型、雲和楓葉都由程式建立，沒有外部模型或圖片素材。

## 啟動方式

直接在瀏覽器開啟 `index.html` 即可；不需要建置工具或後端。首次載入需要網路，以從 jsDelivr 下載 Three.js，並從 Google Fonts 下載字型。字型無法載入時會使用系統字型。

Three.js 使用 **0.149.0（r149）**，透過 `https://cdn.jsdelivr.net/npm/three@0.149.0/build/three.min.js` 載入。程式使用 `THREE.WebGLRenderer`。採用一般 script 而非 ES module，因此本機 `file://` 開啟也能載入 `main.js`。

## 操作

- 在畫布上用滑鼠或手指左右拖曳，水平旋轉相機；動畫在拖曳期間持續播放。放開數秒後，相機會緩慢自轉。
- 點擊右上方的速度按鈕，依序切換 **1×、4×、¼×**。按 **Space** 也可以切換。
- 在網址後加上 `?debug` 可顯示 FPS 和楓葉數量。

## 日夜循環

`DayNightCycle` 使用 `requestAnimationFrame` 傳入的 `deltaTime` 推進時間，預設每 **15 秒** 完成一輪。五個關鍵狀態依序是白天、黃昏、夜晚、黎明、白天（進度 0、0.25、0.5、0.75、1）。每段使用 smoothstep 內插天空漸層、霧色與密度、半球光、環境光及定向光的顏色與強度，讓交界處的變化平滑。太陽與月亮沿相反的路徑移動，夜晚的星點逐漸顯現。

燈光因子從循環進度 0.15 開始升高，在 0.27 完全點亮；從 0.65 開始降低，在 0.74 完全關閉，因此黃昏會自動亮燈，黎明前會熄燈。此因子同時控制鐵塔、鳥居、五重塔和路燈的 `PointLight` 強度與共用材質的自發光強度。

## 楓葉與效能

`MapleLeafSystem` 以一個自訂葉片輪廓和四個 `InstancedMesh` 繪製固定的 **132 片**楓葉。每片葉子有獨立的下落速度、左右擺動、水平風速與翻轉速度。葉子落出場景或飄離右邊後，會重設到空中，實例數與記憶體用量不會隨時間增加。更新時重用同一個 `Object3D` 來組裝實例矩陣。

渲染像素比上限為 1.7，陰影貼圖為 1024²；楓葉、草叢和小裝飾不投射陰影。雲朵使用低面數球體，建物使用基本幾何體與 `MeshToonMaterial`。視窗尺寸改變時會更新 renderer 和相機比例；320 × 200 的 iframe 中會縮小 HUD，保留可觸控的速度按鈕和拖曳區域。

## 視覺素材

沒有使用外部紋理、照片、模型或音效。太陽及月亮的光暈是在記憶體中用 Canvas API 畫出的徑向漸層。字型來源為 [Google Fonts 的 DM Sans 和 Manrope](https://fonts.google.com/)。
