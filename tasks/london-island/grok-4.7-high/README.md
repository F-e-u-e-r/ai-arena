# 漂浮倫敦島 · 四季

卡通風格的空中倫敦小島。大笨鐘在中央，倫敦眼與倫敦塔橋分坐兩岸，泰晤士河在島面上起伏。場景會自己走完白天、黃昏、夜晚、黎明，也會在春霧、夏日、秋楓、冬雪之間過渡。

不需要建置，也不需要後端。

## 如何啟動

用瀏覽器直接打開 `index.html`（需要網路，以便從 CDN 載入 Three.js），或在這個資料夾啟動靜態伺服器：

```bash
python3 -m http.server 8080
```

然後開啟 `http://localhost:8080/`。

最小預覽約 320×200（16:10）。場景會填滿 iframe；季節與日夜按鈕固定在底部，不換行、不溢出。較寬的視窗會顯示一行操作提示。

## Three.js 版本與引入方式

- **版本**：r134（`0.134.0`）
- **引入**：`index.html` 以傳統 script 載入 UMD 建置  
  `https://cdn.jsdelivr.net/npm/three@0.134.0/build/three.min.js`  
  全域名稱是 `THREE`。
- **渲染器**：`THREE.WebGLRenderer`，卡通材質為 `MeshToonMaterial`（4 階硬邊 gradient map）。水面是 `MeshStandardMaterial`，方便保留一點高光。
- **為什麼不用 ES module**：`file://` 開本地模組會被瀏覽器 CORS 擋住。OrbitControls 附加元件也是 ESM，所以相機軌道是自己寫的。
- **外部貼圖**：沒有。時鐘面、英國國旗、粒子圓點、卡通 gradient、島下的接觸陰影都是 canvas 即時畫的。

## 日夜循環

一圈 **15 秒**（`DAY_LENGTH`）。時鐘 `t` 從 0 到 1：

| t | 時刻 | 太陽 |
| --- | --- | --- |
| 0.00 | 正午 | 仰角 +1，在頭頂 |
| 0.25 | 日落 | 仰角 0，在 +X |
| 0.50 | 午夜 | 仰角 −1 |
| 0.75 | 日出 | 仰角 0，在 −X |

太陽方向只有一處計算：`elev = cos(2πt)`，方位角 `= 2πt`。月亮在相反方向。光照強度跟這個仰角走。因為相機是往下看的模型視角，真正的天頂圓盤不會進畫面，所以看得見的太陽與月亮改放在島外一圈低弧上，方位仍跟時鐘走。天空、環境光、半球光、太陽色、霧色都在同一組關鍵影格上做 smoothstep，所以不會跳色。

定向光在太陽落到地平線下之後仍維持一個很低的仰角，避免陰影攝影機翻面；強度則隨著仰角降到 0。月亮光在夜間補上冷色。

**地標燈光**（大笨鐘鐘面與窗、倫敦眼輪框、塔橋窗與點光源）：

- `t` 0.18→0.26 淡入（黃昏開始）
- 夜間維持
- `t` 0.64→0.72 淡出，在黎明（0.72）之前關掉

手動點「晝 / 昏 / 夜 / 曉」會用 0.7 秒走時鐘上的短路徑（跨過午夜不會倒轉一整圈），然後繼續自動日夜。

## 四季

一季 **10 秒**，交界 **2.8 秒** smoothstep（`SEASON_LENGTH`、`SEASON_BLEND`）。權重始終加總為 1。

| 季節 | 畫面 |
| --- | --- |
| 春 | 霧距拉近、地平線發白、慢速霧粒 |
| 夏 | 霧退開、陽光加強、夜間有螢火 |
| 秋 | 楓葉下落，左右擺、自轉 |
| 冬 | 雪花、樹冠與屋頂積雪、冷色天空 |

預設自動輪替。點季節鈕會停在該季，並用指數緩動把權重收到 1（大約 1 秒）。「循」或鍵盤 `C` 恢復自動。草、樹、河的顏色每幀由四季權重混合，不另建材質。

## 粒子與效能

- 楓葉最多 **110** 張、雪最多 **150** 片，都是 `InstancedMesh`。
- 每顆粒子是槽位裡的純資料。死亡時索引回到 free list，下一幀才能再被生成。不會每幀 `new` 網格。
- 生成速率隨季節權重上升；池滿就丟掉多餘的生成累加器，所以長時間跑也不會長大。
- 落葉：`x = x0 + sin(ωt+φ)·amp` 左右擺，歐拉角累加自旋，重力有終端速度。碰到草坪或掉出島緣就回收，接近地面時縮小，避免突然消失。
- 雪花每幀對齊相機，再繞視線轉，所以小畫面仍看得到薄片。
- 春霧與夏夜螢火是固定長度的 `Points` 緩衝，只改寫座標。
- `deltaTime` 上限 0.05 秒，分頁切回時先丟掉累積的 delta，避免補幀風暴。
- 陰影貼圖 1024、像素比在小畫面封頂 1.25。水面位移每幀從基準緩衝重算，不會把頂點越推越遠。
- 音效用一顆循環噪音緩衝加兩次濾波，鳥叫的 oscillator 在 `onended` 斷線。預設靜音，按「聲」或 `M` 才建立 `AudioContext`。

## 相機

自製軌道，不是 OrbitControls。

- 唯一的姿態是 `yaw` 與 `pitch`。`yaw = 0`、`pitch = 0` 時相機在目標的 +Z，朝 −Z 看。
- 指標在畫布上左右拖會減少 yaw（與 OrbitControls 同方向）；上下拖只微調 pitch，並夾在約 13°–53°。
- 拖曳時 `requestAnimationFrame` 不中斷，島仍浮動、輪仍轉、粒子仍落。
- 使用者還沒拖過之前，視角會很慢地自轉；一拖就停，把畫面交給操作。
- 滾輪可拉近／拉遠。視窗或 iframe 尺寸變了會重算距離，讓整座島留在畫面裡（`ResizeObserver`）。
- 方向鍵也能轉。

## 操作

| 輸入 | 作用 |
| --- | --- |
| 拖曳 | 旋轉視角 |
| 滾輪 | 縮放 |
| 春夏秋冬 / `1`–`4` | 切季節（暫停自動） |
| 晝昏夜曉 / `5`–`8` | 跳到該時段，0.7 秒過渡 |
| 循 / `C` | 恢復四季自動 |
| 聲 / `M` | 環境音（風、秋葉沙沙、春夏白天的鳥） |
| 方向鍵 | 微調視角 |

右上角是 FPS 與目前粒子數。

## 場景內容

島體會上下浮動。中央是用方塊與錐體搭的大笨鐘（四面時鐘，秒針走真實時間）與西敏宮側翼。倫敦眼的輪子持續旋轉，座艙反向轉所以保持正立。塔橋有吊索、高架走道，橋面做很小的開合呼吸。河面頂點每幀位移。雲會漂移，三隻海鷗繞島飛。

設計取捨：日夜與季節都寫成權重／關鍵影格，而不是切場景；粒子用固定池而不是每片葉子一個 Mesh。這樣長時間切氣候不會累積物件，小 iframe 也還轉得動。
