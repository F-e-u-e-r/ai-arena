# Savanna — A living landscape

以原生 HTML、CSS、JavaScript 與 Canvas 2D 繪製的非洲草原生態動畫。包含 3 隻獅子、3 隻大象、2 隻豹、6 種天氣、每 60 秒輪替的乾／濕季，以及適合 320 × 200 iframe 的精簡操作介面。

## 啟動

直接以現代瀏覽器開啟 **`index.html`**。不需要安裝套件、建置、後端或啟動伺服器，也不需要網路連線。

- `index.html`：頁面結構、可存取的控制按鈕、圖示與 field guide。
- `style.css`：完整頁面、手機、低高度 iframe、全螢幕與減少動態效果的版面。
- `main.js`：所有動畫、程序繪圖、生態狀態與音效。採用普通 `defer` script，可在 `file://` 正常執行。

所有動物、地形、樹木、雲、天氣與縮圖都是自行以 Canvas 繪製；沒有外部圖像、Sprite、字型、函式庫或素材授權依賴。按鈕使用內嵌 SVG 圖示，生態場景完全由 Canvas 2D 渲染。

## 操作

點選天氣按鈕或乾／濕季按鈕即可切換。切換不重建動物，也不改寫牠們的水平位置。選取物種卡片會標示該家族；點選或滑過動物可查看名字與目前狀態。

| 按鍵       | 功能                                                     |
| ---------- | -------------------------------------------------------- |
| `1`–`6`    | Sunny、Rain、Heavy Rain、Snow、Thunderstorm、Tornado     |
| `S`        | 切換季節，重新計算 60 秒週期                             |
| `Space`    | 暫停／繼續生態；焦點在按鈕時保留原生按鈕操作             |
| `M`        | 開啟／關閉自然音效                                       |
| `F`        | 展開／離開全螢幕；不支援 Fullscreen API 時使用頁面內展開 |
| `D`        | FPS、使用中／可用粒子、雷擊次數與龍捲風目標              |
| `G` 或 `?` | 開啟 field guide                                         |
| `Esc`      | 關閉指南或退出頁面內展開                                 |

瀏覽器啟用 `prefers-reduced-motion` 時初始暫停；可自行按播放。音效預設關閉，僅在使用者操作後建立 Web Audio 音源。音效由程式合成，包含風、雨感背景、鳥聲和低沉雷聲。

## 為何選擇 Canvas

Canvas 適合同時繪製多層背景、可變形的動物肢體與數百個短生命週期粒子，無須為每滴雨建立 DOM 節點。動物的身體、耳朵、腿、鼻子、尾巴與豹斑可用路徑和分層繪圖統一控制。畫面使用 1600 單位寬的座標系，高度配合實際 viewport；動物保持等比例，不會被拉長。

背景包括漸層天空、日暈、移動雲層、遠山、多層草地、小型遠景金合歡、蜿蜒小徑、水池及前景草。山層有不同幅度的緩慢視差，葉冠、鳥翼、水紋與草梗另行動畫；種子亂數固定植被紋理，避免畫面閃爍。

## 系統架構

| 類別                              | 責任                                               |
| --------------------------------- | -------------------------------------------------- |
| `SavannahApp`                     | 單一動畫迴圈、事件連結、Canvas 尺寸、UI 與深度排序 |
| `Animal`                          | 移動、群體間距、姿態、包圍盒、循環路徑與分層繪圖   |
| `Lion` / `Elephant` / `Leopard`   | 各物種的狀態轉移及習性                             |
| `SeasonManager`                   | 60 秒季節週期、手動切換與漸變參數                  |
| `WeatherManager`                  | 單一天氣狀態、天候過渡與次要地面效果               |
| `ParticlePool` / `ParticleSystem` | 固定容量粒子、發射、回收及繪製                     |
| `LightningSystem`                 | 動態安全走廊、閃電路徑與逐幀安全確認               |
| `Tornado`                         | 最近動物追逐及旋轉漏斗                             |
| `Landscape`                       | 程序式美術、地形快取、動態背景                     |
| `Soundscape`                      | 按需建立的 Web Audio 背景與短音效                  |

管理器以 `EventTarget` 發出切換事件；動物保留各自狀態。主迴圈先更新季節，再更新動物，最後更新天氣與雷擊安全區。

## 動物習性與季節

- **獅子**：群體慢速巡邏、呼吸和走路姿態，以及短暫趴臥休息。雄獅、母獅和幼獅造型不同；乾季更常休息。
- **大象**：最慢的家族移動，以前方同伴的循環距離調整速度。包含幼象、擺耳、搖尾、抬鼻嗅聞；口渴程度隨時間增長，經過水池時會停下喝水。
- **豹**：兩隻有不同花紋的個體分別活動，步速較快，會切換潛行、接近樹木、垂直攀爬、停棲與下降狀態。暴風時會從樹上下來。
- **循環**：動物均沿由左到右的路徑移動；跨越右邊界時，前半身從左側連續進入，後半身繼續離開右側。邊界兩端繪製同一物件的可見部分，不配置新動物，讓 8 個個體持續出現在場景內。開場是預先運行過的自然場景，以免使用者先等待空白草原。
- **乾季**：金黃色草地、家族較緊密、獅子較常休息、口渴增加較快。
- **濕季**：天空與草地逐漸轉綠、水池擴大、動物速度增加約 28%、家族活動範圍加大。
- **天氣**：細雨稍微加快活動；大雨、雷雨和龍捲風令動物警戒並加速；雪天較緩慢。強烈天氣會結束休息，攀爬中的豹會先下降。龍捲風使家族更緊密。

季節每 **60 秒有效模擬時間** 自動輪替；暫停或切到背景分頁時不累積時間。手動選擇季節重新開始週期。以 `1 - exp(-rate * deltaTime)` 插值季節和天色參數，確保不同更新率的過渡一致。

**雪是想像性的高地展示模式，並非典型 Serengeti 氣候。** 為表現季節對天氣可用性的影響，只有乾季能選擇雪；濕季停用雪按鈕。雪天轉入濕季會自然切換為雨，原有積雪逐漸融化。雨水積成淺水窪，天晴後緩慢蒸發。

## 雷暴安全區演算法

1. 動物完成當幀移動後，計算每隻動物的保守包圍盒，包含擺動的尾巴、象鼻、獅鬃、攀樹姿態與抗鋸齒邊界。
2. 取所有動物包圍盒的水平投影，包含跨越邊界時另一側的身體部分；左右再擴張 46 個世界單位，排序並合併禁區。
3. 在畫面寬度內求禁區的補集，只使用至少 42 單位寬的空白走廊。沒有空位就略過這次雷擊，稍後重試。
4. 主閃電的 **9 個頂點與支線都限制在同一走廊內**。任意相鄰頂點之間的線段也必然留在走廊內；因此不必賭隨機落點是否安全。
5. 驗證整條閃電的水平範圍，額外保留 28 單位間隔，足以涵蓋最寬 23 單位光暈。
6. 閃電顯示約 0.2 秒。在其存在期間，每幀移動後及繪製前都重新驗證；若任何動物進入走廊，立即取消閃電，不繪製危險的一幀。

這是保守的幾何保證，連樹上的豹也包含在內；沒有安全位置時寧可不產生閃電。減少動態效果模式不繪製背景亮光。

## 龍捲風追逐

每次更新計算漏斗底部到所有畫面內動物地面位置的平方距離，選擇最近者。將方向向量正規化，按 `10 × deltaTime` 的最大距離前進；不傳送、不傷害或吸走動物。警戒中的動物跑得更快。漏斗由半透明橢圓旋渦帶組成，回收的碎屑粒子沿隨高度擴張的螺旋向上飛散。`D` 可查看當前追逐對象。

## Object Pooling 與效能

- 啟動時只建立 **1400 個粒子物件**，分成 `free` 與 `active` 陣列。
- `acquire()` 從可用堆疊取物件並重設所有欄位；容量用盡則略過發射，絕不擴張配置。
- `release()` 用最後一個活躍粒子補入刪除位置，再回到可用堆疊；O(1) 回收，不用 `splice()`。
- 雨滴落地後可直接把同一物件轉換成水花，不分配子物件。
- 切換天氣同步回收全部粒子、歸零發射餘量，清除閃電。新的粒子只屬於新天氣；場景顏色仍平滑過渡。
- 每個粒子都有生命上限與越界回收。`active.length + free.length` 始終等於 1400。
- **只有一個 `requestAnimationFrame`**。物理使用秒為單位的 `deltaTime`，上限 0.05 秒；背景分頁回來後不補算大量時間。
- 固定地形、植被與遠景樹繪製到離屏 Canvas；僅在尺寸或季節／天色跨過量化門檻時重畫。前景擺動和動物獨立渲染。
- 裝置像素比上限為 2；小於 600px 的場景降低粒子發射量。雨線合併成一條批次路徑。
- 動物、背景資料及粒子容量固定；不保留逐幀歷史。UI 每 0.25 秒更新，事件監聽只註冊一次。
- 音量與濾波參數只在目標改變時排程，不逐幀新增 audio automation。短暫音效結束會斷開 audio nodes；離開頁面時取消動畫、解除 observer / listeners、清空粒子並關閉 AudioContext。

## 響應式與可存取性

一般畫面顯示完整 field observatory；小高度 iframe 隱藏介紹、物種卡與頁尾，保留場景、6 個天氣按鈕、2 個季節按鈕、播放與聲音操作。320 × 200 模式的控制列以圖示顯示，按鈕保有完整名稱、`title`、`aria-pressed` 與焦點樣式。桌面與行動版使用同一套狀態，沒有另一個「展示用」靜態預覽。

原生 `<dialog>` 提供鍵盤焦點管理；重要變更透過 `aria-live` 通知。全螢幕不可用的 iframe 仍可用頁面內展開。浮動效能資訊預設隱藏，避免遮住小場景。

## 檢查方式

直接開啟檔案，逐一切換 6 種天氣及兩個季節；查看動物會保持位置且繼續活動。等候 60 秒確認自動季節轉換，觀察右側樹木上的豹及雷擊避開動物。將 viewport 設成 320 × 200，確認 8 個環境按鈕與場景操作仍可點選。

開發者工具可查閱 `window.savanna.diagnostics`，或按 `D` 查看即時數據。`window.savanna.advance(dt)` 將模擬與繪製分開，方便執行固定步長、30 分鐘以上的加速穩定性檢查；這不等於實際裝置上完整 30 分鐘的效能量測。池容量、粒子總數不變式、安全閃電及有限座標可在每步檢查。

交付前已通過 JavaScript 語法檢查，以及以 DOM／Canvas 替身執行的 **47.8 分鐘加速模擬**：涵蓋所有動物狀態、220 次持續天氣切換、180 次連續天氣選擇、500 組隨機雷擊障礙、粒子身份與容量不變式、季節可用性、位置保留與追逐速度上限。本環境的沙箱阻止啟動瀏覽器，因此未聲稱已完成真實瀏覽器的 UI 檢查或 30 分鐘實機效能量測。

這是一個有生態習性啟發的藝術觀察窗，而非精確的動物學或氣象模擬。
