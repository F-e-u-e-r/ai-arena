# Wildlands — The Living Savannah

一個使用原生 HTML、CSS 與 Canvas 2D 製作的單頁非洲草原生態動畫。所有動物、地形、樹木、雲與粒子皆由程式繪製；沒有外部圖片、Sprite、函式庫或後端。

## 啟動與操作

直接在瀏覽器開啟 `index.html`。不需要安裝套件或啟動伺服器。

- 下方六個按鈕切換 Sunny、Rain、Heavy Rain、Snow、Thunderstorm、Tornado；鍵盤 `1`–`6` 也可切換。
- 季節按鈕或鍵盤 `S` 切換乾／濕季；每 60 秒也會自動輪轉。
- 雪是乾季的罕見事件，濕季時其按鈕停用。若雪景中進入濕季，天氣會轉為雨。
- 大畫面角落顯示 FPS 和目前粒子數。小型 iframe 會隱藏次要文字，但六種天氣與季節控制仍可操作。

## 為什麼選 Canvas

地形、動物、天氣需要在同一個動畫時鐘下逐幀組合。Canvas 2D 讓多層漸層、手繪曲線、角色局部座標變換和大量粒子共享一次渲染流程；不需要建立或持續更動數百個 DOM 節點。畫布以固定 700 單位的世界高度繪製，寬度隨容器比例改變，並以最高 2 倍的裝置像素比保持清晰。

## 架構與生態行為

`SavannahApp` 擁有唯一的 `requestAnimationFrame` 迴圈；所有更新使用以秒計算、上限為 0.05 秒的 `deltaTime`。`EventBus` 傳遞天氣及季節事件，`WeatherManager`、`SeasonManager`、`Landscape` 和三種 `Animal` 子類分別管理自身責任。切換天氣或季節不會重建動物，也不會重設牠們的位置。

- **獅子（2）**：一公一母維持隊形，巡邏與短暫休息交替；乾季更常休息並靠近同伴。
- **大象（2）**：以緩慢步伐成群遷移；接近水坑時可能喝水，亦會抬鼻。
- **豹（2）**：各自快速潛行，偶爾衝刺；靠近刺槐後可能攀爬，使用垂直位移展示上下樹。

所有動物朝右移動，到達右邊後從左邊再次進入；邊界附近會繪出同一動物的另一個視圖，避免循環時突然消失。濕季提升活動速度與豹的衝刺機率；乾季強化群聚和獅子的休息傾向。暴雨、雪與雷雨會降低行進速度；龍捲風則引發加速。背景、草地、水坑與亮度也隨季節平滑轉換。

## 天氣、粒子與效能

`ParticlePool` 預先建立 800 個可重複使用的粒子物件，使用 `active` 和 `free` 陣列管理。取得粒子時重設欄位；生命結束時以交換尾元素的方式 O(1) 回收。天氣切換時立即把所有舊粒子送回 `free`，接著依新天氣的固定速率和數量上限產生粒子。因此反覆切換不會堆積舊雨滴、雪花或塵埃。雨滴可轉為地面漣漪；雨天會出現積水；龍捲風的塵粒圍繞漏斗運動。

地形裝飾座標由固定種子的亂數序列在啟動時產生一次。動物和渲染排序陣列常駐；Canvas 只在尺寸變化時重新設定解析度。暫停的分頁恢復時會重設上一幀時間，避免極大時間步長。數量上限、單一動畫迴圈與粒子回收使長時間執行的記憶體用量保持有界。

## 雷暴安全區演算法

每次產生閃電時，`WeatherManager.findSafeStrike` 會掃描整個可見地面，僅接受與**所有六隻動物的即時 X 座標**相隔超過「動物碰撞半徑 + 105 世界單位」的位置，邊界處亦納入動物的循環視圖。額外距離涵蓋主閃電的曲折路徑、分支和短時間移動。閃電存在的每一幀，`isStrikeSafe` 都會重新檢查所有動物；若原位置不再安全，就改找安全位置。找不到安全位置時只顯示高空閃光與不落地的短閃電。這個保守的水平安全帶覆蓋整個動物高度，因此不會擊中攀樹中的豹。

## 龍捲風追逐

每幀尋找與龍捲風水平距離最近的動物，以最高 18 世界單位／秒向目標靠近；此速度低於動物的正常遷移速度。漏斗形狀、旋轉線與池化塵粒同步跟隨其位置。

## 響應式預覽

在 320 × 200 的 iframe 中，場景保留約 150px 高度；六個天氣圖示和季節按鈕排成一列，均可點擊。場景 HUD 縮為角落的短文字，避免遮住動物。放大視窗後會顯示完整標題、按鈕名稱、倒數與偵錯資訊。
