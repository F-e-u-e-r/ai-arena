# 非洲大草原生態系統

單頁 Canvas 2D 動畫。七隻動物（獅 3、象 2、豹 2）由左向右循環，天氣與乾／濕季會改變顏色、粒子與行為。沒有框架、沒有建置、沒有外部圖片。

## 如何啟動

用瀏覽器直接開啟 `index.html`（`file://` 即可）。腳本是傳統 `<script>`，不是 ES module，所以不需要伺服器。若要走 HTTP，在此目錄執行：

```bash
python3 -m http.server 8765
```

然後開啟 `http://127.0.0.1:8765/index.html`。

底部一排是唯一主天氣（Sunny、Rain、Heavy Rain、Snow、Thunderstorm、Tornado）與季節按鈕。乾季與濕季每 60 秒自動對調，也可按季節按鈕手動切換。快捷鍵：`1`–`6` 切天氣，`S` 切季節，`D` 在右上角加上物件池用量與閃電計數。視窗縮放時畫布跟著變；約 320×200 時天氣鈕只留圖示，季節鈕留 Dry／Wet。

## 為何選擇 Canvas

動物、視差（天空、雲、遠山、草、前景草葉）、天氣粒子與閃電都要同一幀、用 `deltaTime` 一起更新。Canvas 2D 可以把這些畫進同一張位圖，不用為每隻動物或每顆粒子建 DOM。裝置像素比上限 1.75，繪製座標維持 CSS 像素。配色全部在程式裡插值，沒有點陣圖。

## 粒子管理與效能策略

`requestAnimationFrame` 驅動主迴圈，`deltaTime` 上限 0.05 秒，避免分頁切回時一次跳太大。`ParticleSystem` 只持有正在用的粒子陣列；死亡用 swap-remove 交還物件池。每幀 `maintain` 先對齊目標數量，多的回收、少的最多補約 42 顆，避免切天氣的那一幀一次配置幾百顆。

切天氣時 `releaseAll` 把活粒子全部還池，並把計數清零。`update` 不改計數；下一幀 `maintain` 前先 `_recount()`，避免雨滴就地變成水花時帳目漂移。雨天地面會積水並濺起水花；龍捲風的碎屑繞著漏斗轉並上升。`prefers-reduced-motion` 時粒子目標約降到 28%。小畫面再用畫面面積係數降低目標數量。

## 雷暴安全區演算法

實作在 `js/weather.js` 的 `pickSafeStrikeX`。閃電是一條垂直柱。

1. 用每隻動物當下的左右邊界，左右各外擴 16px，裁到畫面寬度內，得到禁止區間。
2. 依左緣排序後合併重疊區間。
3. 禁止區間在 `[0, width]` 裡的補集就是安全縫；窄於 18px 的縫丟掉。
4. 沒有可用縫就回傳 `null`，只閃雲、不打柱，絕不把落點硬推到動物身上。
5. 在選中的縫內縮邊後取一個 x，折線的每個點都夾在該縫裡。

柱子活著的每一幀，`columnHitsAnimal` 再用即時邊界檢查整條柱（含分叉）。動物走進柱子就在繪製前熄滅。`getBounds` 與碰撞檢查共用一塊暫存物件，呼叫不可巢狀。

## 動物習性與季節變化邏輯

- **獅子**（一雄兩雌）：同一狀態機，一起走、慢速巡邏或短暫停下。間距用速度倍率追趕或放慢，不會被彈回左邊。龍捲風時取消休息並向前加速。
- **大象**（成體與幼體）：成群慢行，偶爾喝水（水坑波紋）或抬鼻。下雪或龍捲風時取消喝水。
- **豹**：單獨、較快，會潛行。經過空的樹時有機率爬上（垂直抬升並旋轉），同一棵樹同時只給一隻。龍捲風時從樹上落下並不再爬。

走出右緣後從左側再進入（爬樹途中不換邊）。換天氣或季節只改目標速度與動作機率，位置與速度用補間，不重置。

季節的 `blend` 在 0（乾）與 1（濕）之間用指數補間。累積模擬時間滿 60 秒才翻轉目標；手動切換會把累計歸零，避免立刻被自動輪轉打回來。濕季較快、間距較鬆、喝水與爬樹較頻繁；乾季較慢、較聚、休息較多。天氣再乘上一層：雨與大雨變慢並多休息，雪更慢且少爬樹，雷雨加快、少休息、多爬樹，龍捲風幾乎不休息、間距拉開、不爬樹。乾季雪的密度約 22%，隨 `blend` 升到濕季的全量；按鈕兩季都可選。

龍捲風每幀用平方距離找最近的動物，只沿水平方向追。速度是目前象群巡航速度的 58%（且不低於一個小下限），所以走路的象會拉開距離，停下的動物會被慢慢追上。漏斗留在地面。有動物從右側繞回左側變成最近目標時，漏斗會轉向。

## Object Pooling

`js/pool.js` 的 `ObjectPool` 在建構時就建立 520 顆粒子，上限也是 520。`acquire` 滿了回傳 `null`，呼叫端跳過那次生成。`release` 會重置並用 `_pooled` 擋重複歸還。因此長時間切換天氣時 `created` 維持 520，不會隨粒子數成長。

## 設計取捨

- 用傳統 script 而不是 `type="module"`，這樣直接開檔不會被瀏覽器擋住。
- 雪在乾季仍可手動開啟，只是粒子變少，而不是把按鈕鎖死。
- 龍捲風只做水平追逐，漏斗腳留在地面，速度低於象的巡航。
- 閃電若在生成後被動物走進，會在畫出前熄滅，而不是改道。
- 手動切季節會重算 60 秒。
- 開場動物已在畫面內，之後才做左右循環。
- 沒有使用第三方 sprite，造型都是 Canvas 路徑。
